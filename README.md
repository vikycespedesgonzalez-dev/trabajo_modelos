# Amenazas naturales y ganancias mensuales (VIII EME 2025)

Repositorio reproducible del informe de Modelos Lineales.

[![Launch RStudio Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/vikycespedesgonzalez-dev/trabajo_modelos/HEAD?urlpath=rstudio)

## Cómo ejecutar el código
1. Hacer clic en el botón **launch binder** de arriba para abrir RStudio en el navegador.
2. En el panel inferior derecho (*Files*), abrir el archivo `nombre_de_tu_script.R`.
3. Presionar **Source** (o `Ctrl + Shift + Enter`) para ejecutar todo el análisis.
